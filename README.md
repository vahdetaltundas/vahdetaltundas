## 👨‍💻 Biraz benden

İstanbul'da yaşayan bir bilgisayar mühendisiyim. **Full-stack web geliştirme** ve **yapay zeka** üzerine çalışıyor, Eskişehir Osmangazi Üniversitesi'nde yapay zeka odaklı yüksek lisansıma devam ediyorum.

Bir fikrin arayüzünden backend mimarisine kadar nasıl şekillendiğiyle ilgileniyorum. Özellikle **LLM ajanları, RAG ve otomasyon** sistemlerini web uygulamalarıyla buluşturmayı seviyorum.

Burası geliştirdiğim projeleri, denemelerimi ve öğrenirken keşfettiklerimi paylaştığım alan.

## 🧭 İlgi alanlarım

- **Full-Stack Web** — Kullanıcı arayüzleri, backend servisleri ve API tasarımı.
- **AI & LLM Systems** — Bağlam kullanan uygulamalar, araç kullanan ajanlar ve ajan orkestrasyonu.
- **Veri & Otomasyon** — Veri modelleme, servis entegrasyonları ve iş akışları.
- **Yazılım Mimarisi** — Modüler, anlaşılır ve sürdürülebilir sistemler.
